## About This Project

This project covers JavaScript variables,data types,type checking,type conversion,type coercion,floating-point behaviour,code review,and refactoring.

While working through the challenges,I learnt how important it is to understand the type of a value before using it in a calculation.I also learnt how JavaScript can automatically convert values,and why explicit type conversion can make code easier to understand and prevent unexpected results.

The project also helped me practise explaining my code and the reasoning behind the decisions I made,which is important when answering JavaScript technical interview questions.

## What The Project Covers

- `var`,`let` and `const`
- JavaScript data types
- The `typeof` operator
- Type conversion
- Type coercion
- `Number()`
- `parseInt()`
- `parseFloat()`
- `Boolean()`
- `String()`
- `NaN` and `Infinity`
- Floating-point numbers
- `Number.EPSILON`
- Code review
- Refactoring
- Template literals
- Input validation
- JavaScript interview-style questions

## How To Run The Project

Make sure Node.js is installed.

Open the terminal inside the project folder and run:

```bash
node sijabulile-ncube-module2.js
```

The results of all ten challenges will be displayed in the terminal.
