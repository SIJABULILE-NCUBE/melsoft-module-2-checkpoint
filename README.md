## About this project

This repository holds my answers to ten interview style JavaScript challenges from Module 2.Each challenge is written the way I would explain it to an interviewer,with my predictions,my mistakes and what I learnt from them left in the comments.The challenges cover variable declarations,typeof,converting between types,implicit coercion,floating point maths,reviewing and refactoring someone else's code,and building a small receipt generator.My biggest takeaway is that JavaScript almost never stops me when types clash,it converts silently and hands back a wrong answer instead,so I now convert values on purpose and validate input before I use it.
